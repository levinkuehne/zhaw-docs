# Potenzmengen

Potenzmenge => eine Menge von Mengen.

$P(A)$ => die Menge aller Teilmengen von $A$

## Definition

![[../media/file-20261001192746514.png]]

## Beispiel

Was sind alle möglichen Teilmengen von $\{1, 2\}$?

- leere Menge
- $\{1\}$
- $\{2\}$
- $\{1, 2\}$

![[../media/file-20261001192828655.png]]

![[../media/file-20261001192953614.png]]

Bei Potenzmengen mit Variablen kann man substituieren, damit es kein Durcheinander mit Klammern gibt.

![[../media/file-20261001193223452.png]]

## Eigenschaften

> Die leere Menge ist immer Teilmenge von Mengen.
> Eine Menge ist immer Teilmenge von sich selbst ($A \subseteq A$).

> Wenn $A$ eine Teilmenge von $B$ ist, ist $P(A)$ auch Teil von $P(B)$.

$$P(A) = P(B) \iff A = B$$

Ist $A$ eine endliche Menge mit $n$ Elementen, so hat $P(A)$ genau $2^n$ Elemente.

# Relationen

Eine Relation von $A$ nach $B$ ist ein Tripel $R = (G, A, B)$ und besteht aus drei Komponenten:

| Komponente     | Beschreibung                       |
| -------------- | ---------------------------------- |
| **Quellmenge** | beliebige Menge $A$ (Definitionsbereich) |
| **Zielmenge**  | beliebige Menge $B$ (Wertebereich) |
| **Graph**      | $G \subseteq A \times B$           |

![[../media/file-20261001201716256.png]]

> Gilt $A = B$, dann nennen wir $R$ eine **homogene Relation** auf $A$ (wenn Quell- und Zielmenge gleich sind).

![[../media/file-20261001201900643.png]]

## Symmetrie und Antisymmetrie

**Symmetrisch:** Wenn $x$ in Relation zu $y$ steht, muss auch $y$ in Relation zu $x$ stehen.

![[../media/file-20261001204308157.png]]

**Antisymmetrisch:** Es gibt keine zwei verschiedenen Elemente, die in beide Richtungen in Relation stehen. Wenn $a$ in Relation zu $b$ ist **und** $b$ in Relation zu $a$, folgt immer $a = b$.

![[../media/file-20261001204423329.png]]

Es gibt Relationen, die symmetrisch **und** antisymmetrisch sind.
Es gibt auch welche, die nichts von beidem sind.

![[../media/file-20261001204850247.png]]

Die leere Menge in Relation einer beliebigen Menge ist symmetrisch und antisymmetrisch.
=> keine Relation

![[../media/file-20261001205026890.png]]

## Totalität und Eindeutigkeit

- **Linkstotal / linksvollständig** heisst: Von jedem Punkt auf der linken Seite geht ein Pfeil weg auf die rechte Seite.
- **Rechtstotal / rechtsvollständig:** Zu jedem Punkt in der Zielmenge gibt es einen Pfeil.
- **linkseindeutig**: zwei inputs können nicht denselben output haben
- **rechtseindeutig**: ein input kann nicht zwei verschiedene outputs geben
Eine Funktion muss rechtseindeutig sein, weil der gleiche Input immer den gleichen Output geben soll.

![[../media/file-20261001210125309.png]]

**Definition von Mr. Claude**

**Linkstotal:** Von jedem Punkt links geht **mindestens ein** Pfeil weg. (Es dürfen auch mehrere sein, das regelt erst die Rechtseindeutigkeit.)  
Formal: ∀a ∈ A ∃b ∈ B: (a, b) ∈ R

**Rechtstotal:** Bei jedem Punkt der Zielmenge kommt **mindestens ein** Pfeil an.  
Formal: ∀b ∈ B ∃a ∈ A: (a, b) ∈ R

**Linkseindeutig:** Zwei **verschiedene** Inputs können nicht denselben Output haben. Anders gesagt: Bei jedem Punkt rechts kommt **höchstens ein** Pfeil an.  
Formal: (a₁, b) ∈ R und (a₂, b) ∈ R ⇒ a₁ = a₂

**Rechtseindeutig:** Ein Input kann nicht zwei verschiedene Outputs haben. Anders gesagt: Von jedem Punkt links geht **höchstens ein** Pfeil weg.  
Formal: (a, b₁) ∈ R und (a, b₂) ∈ R ⇒ b₁ = b₂
