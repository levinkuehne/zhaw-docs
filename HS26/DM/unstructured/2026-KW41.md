# Funktionen

Funktionen sind Relationen, die linksvollständig und rechtseindeutig sind.

- Quellmenge $A$
- Zielmenge $B$

$$f : A \to B$$

Für jedes Element von $A$ existiert ein Element von $B$, aber nur ein solches Element!

Kann auch so geschrieben werden:

![[../media/file-20261008191904225.png]]

Als Graph:

![[../media/file-20261008191914802.png]]

Bei jedem Input in die Funktion muss etwas herauskommen. Derselbe Input gibt immer denselben Output (rechtseindeutig).

Programmierung: Pure Functions

> **Achtung**
> Bei der Definition von Funktionen mithilfe einer Zuordnungsvorschrift muss diese Vorschrift jedem Element der Quellmenge ein eindeutiges Element der Zielmenge zuordnen.

# Inverse Relation

Jede Relation hat eine inverse Relation (Quell- und Zielmenge bzw. die Paare werden vertauscht). Damit die Inverse einer Funktion wieder eine Funktion ist, muss die Funktion zusätzlich zu linksvollständig und rechtseindeutig auch noch linkseindeutig (injektiv) sein.

![[../media/file-20261008194850307.png]]

Links und rechts werden vertauscht.

![[../media/file-20261008195409897.png]]

![[../media/file-20261008195146657.png]]
