# Funktionen

Funktionen sind Relationen, die linksvollständig und rechtseindeutig sind.

- Quellmenge $A$
- Zielmenge $B$

$$f : A \to B$$


Für jedes Element von $A$ existiert ein Element von $B$, aber nur **ein** solches Element!

Kann auch so geschrieben werden:
![[../media/file-20261008191904225.png]]

Gesprochen heisst das:
- **∀a ∈ A**: für alle a aus A
- **∃! b ∈ B**: es existiert genau ein b aus B (das rot markierte „!“ steht für „genau ein“, also Existenz und Eindeutigkeit)
- **(a, b) ∈ G_f**: das geordnete Paar (a, b) ist Element des Graphen von f
- **b = f(a)**: dieses b ist der Funktionswert von a

Als Graph:

![[../media/file-20261008191914802.png]]

Bei jedem Input in die Funktion muss etwas herauskommen. Derselbe Input gibt immer denselben Output (rechtseindeutig).

# Injektive Funktionen
Eine Funktion ist eine *linksvollständige*, *rechtseindeutige* Relation. Injektive Funktionen sind zusätzlich noch ***linkseindeutig***.

Injektivität: unterschiedliche Inputs = unterschiedliche Outputs, sonst ist es nicht injektiv.

injektive funktion: f(x) = x oder f(x) = x + 1
nicht injektive funktion: f(x) = 1

# Inverse Relation

Jede Relation hat eine inverse Relation (Quell- und Zielmenge bzw. die Paare werden vertauscht). 

Damit die Inverse einer Funktion wieder eine Funktion ist, muss die Funktion zusätzlich zu linksvollständig und rechtseindeutig auch noch linkseindeutig (injektiv) sein.

![[file-20261009152530754.png]]

wenn ursprüngliche funktion linksvollständig war, ist inverse funktion rechtsvollständig.
wenn ursprüngliche funktion linkseindeutig war, ist inverse funktion rechtseindeutig.

![[../media/file-20261008194850307.png]]

Links und rechts werden vertauscht.

## Surjektivität

Surjektivität = zusätzlich noch rechtsvollständig: 
	=> Alles in der Zielmenge kommt als Resultat vor.

Zum beispiel gibt es für jede länge eines strings eine passende grösse des strings

durch verkleinern der zielmenge wird jede funktion surjektiv, wenn man als zielmenge einfach das Bild (image) nimmt.
