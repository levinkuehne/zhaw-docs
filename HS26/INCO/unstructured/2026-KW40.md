# Signed / Unsigned

| Typ          | Beschreibung                                                                                    | Beispiel (Byte)                                                         |
| ------------ | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **Signed**   | Kann **positive und negative** Zahlen sowie die Null speichern (standardmässig bei den meisten Datentypen). | Wertebereich von **-128 bis 127** (Zweierkomplement: das oberste Bit hat die Wertigkeit $-2^7 = -128$) |
| **Unsigned** | Kann **nur Null und positive** Zahlen speichern (keine negativen Werte).                        | Wertebereich von **0 bis 255** (alle 8 Bits zählen die Zahl hoch)       |

## Probleme bei endlichen binären Zahlen

Bei endlichen binären Zahlen können einige Probleme auftreten:

- Es ist nicht jede beliebig grosse Zahl darstellbar.
- Die zahlenmässige Bedeutung eines Bitmusters hängt davon ab, ob man von vorzeichenlosen oder vorzeichenbehafteten Zahlen spricht.
- Bei der Berechnung von Summen oder Produkten kommt es zu Überläufen, wenn das Resultat nicht mehr darstellbar ist.
- Bei vorzeichenlosen Zahlen passieren Überläufe zwischen 0 und der grössten darstellbaren Zahl.
- Bei vorzeichenbehafteten Zahlen passieren Überläufe zwischen der grössten positiven und der kleinsten negativen Zahl.
- Bei Überläufen kann ein falsches Resultat entstehen, wenn das betreffende Überlaufsflag (Carry, Overflow) nicht beachtet wird (was der Normalfall ist).

## Unicode

Unicode beschreibt wie ASCII einen Zeichensatz.

- Unicode fasst alle bekannten Zeichen der verschiedenen modernen und auch historischen Sprachen und Schriften zusammen.
- Damit entfällt (theoretisch) die Inkompatibilität zwischen Dokumenten und Systemen mit unterschiedlichen Zeichensätzen.
- Die Unicode-Zeichentabelle hat Platz für rund 1 Mio. Zeichen (sog. Code Points), wovon erst etwa 10 % belegt sind.
- Version 1.0.0 wurde 1991 publiziert. Seither gab es durchschnittlich alle 15 Monate eine Erweiterung.

## Encoding

Das Encoding definiert, wie Zeichen gespeichert werden.

- Unicode Transformation Format (UTF) definiert 3 Formate:
  - UTF-8
  - UTF-16
  - UTF-32

### UTF-32

- Jedes Unicode-Zeichen wird fix mit 32 Bit codiert.
- 16 Bit würden für moderne Texte eigentlich reichen,
- daher bezüglich Speicherplatz sehr ineffizient.
- Wird selten benutzt.
