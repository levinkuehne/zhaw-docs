# AI / LLM

## Zusammenfassung
- Basierend auf den vorhergehenden Token (Wortteile) wird das nächste Token berechnet.
- Die Anzahl der berücksichtigten Tokens ist begrenzt.
- Token mit hoher Wahrscheinlichkeit werden bevorzugt. (Temperatur)

## Temperatur
0 = nur das wahrscheinlichste antworten (deterministisch)

> desto höher die Temperatur, desto mehr halulu (desto höher ist die wahrscheinlichkeit, dass es ein token mit niedrigerer wahrscheinlichkeit ausgibt.)

## Context Window
typische context windows: 128k -1m

# Git

| Begriff | Bedeutung |
|---|---|
| Remote Repository | Repository auf zentralem Git Server |
| Local Repository | Geklontes Repository in den eigene Dateien |
| Working Copy | Lokales Repo, woran gearbeitet wird |
| add / stage | sagen welche files commitet werden sollen |
| commit | files zum index vom lokalen repo hinzufügen |
| push | lokale commits in remote repo pushen |
