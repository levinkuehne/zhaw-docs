# Strategische Ebene

Normative Ebene definiert Vision, strategische Ebene definiert den **Weg zum Ziel**.

## Beispiel easyJet

- **Vision**: billige Flüge ermöglichen, grösster Marktanteil an Flügen
- **Strategie**: attraktive Angebote, kleinere Löhne, engerer Sitzplatz, sie haben auf online gesetzt
- **Stärken / Schwächen**: mangelnde Qualität, schlechtere / weniger Angebote
- **Umweltfaktoren**: steigende Kerosinpreise, Klimawandel

## Analyse der Ausgangslage

Vertiefen wollen wir dies – stellvertretend für andere Ansätze, die es in diesem Bereich gibt – anhand von folgenden drei Modellen:

- Der SWOT-Analyse
